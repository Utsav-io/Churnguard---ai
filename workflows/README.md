# Workflow export

Place your exported n8n workflow here as `churnguard-ai.json`.

How to export from n8n:
1. Open the ChurnGuard AI workflow.
2. Click the three dots (menu) next to the workflow name.
3. Choose **Download**.
4. Rename the file to `churnguard-ai.json` and put it in this folder.

Before committing, open the file in Notepad and search for `key`, `secret` and `token`. n8n normally stores credentials separately, so no API key should appear.
